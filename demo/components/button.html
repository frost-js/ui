Buttons

Solid variants

Use semantic variants to communicate the purpose of an action.

.btn .btn-{variant}

Gradient variants

Add the gradient treatment to any solid semantic variant.

.btn .btn-{variant} .btn-gradient

Outline variants

Outline buttons retain semantic color with less visual weight.

.btn .btn-outline-{variant}

Element types

The button treatment works consistently across links, buttons, and form controls.

.btn .btn-primary
Link

Sizes

Choose a compact, default, or prominent control size.

.btn-sm .btn-lg

Disabled states

Use the native disabled attribute where possible, or the disabled class with accessibility attributes on links.

disabled .disabled
Link

Responsive layouts

Combine display, grid, and flex utilities to control button width and alignment.

.d-grid .gap-2 .d-md-flex

Toggle buttons

Toggle controls synchronize the active class and pressed state.

data-ui-toggle="button"
