Carousel

Slides

Set the initial item as active and optionally start cycling when the page loads.

.carousel .carousel-inner .carousel-item data-ui-ride="carousel"

Previous and next controls

Target a carousel from dedicated controls to move directly between adjacent slides.

data-ui-slide="prev" data-ui-slide="next"

Indicators

Show the current position and let people select a slide directly.

.carousel-indicators data-ui-slide-to="{index}"

Captions

Add a frosted caption surface and use text utilities to vary its alignment.

.carousel-caption
