Dropdowns

Menu content and states

Menus can contain actions, section headings, dividers, active items, and disabled items.

.dropdown-menu .dropdown-item .fade

Workspace

Split actions and sizes

Keep the primary action immediate while moving related choices into a split menu; button sizing carries through to the toggle.

.dropdown-toggle-split data-ui-reference

Placement and alignment

Placement chooses a preferred side; position aligns the menu along that side. Dynamic menus can adapt when space is limited.

data-ui-placement="*" data-ui-position="*"

Controlled dismissal

Choose which interactions dismiss a menu when users need to make one action, several selections, or an explicit decision.

data-ui-auto-close="inside|outside|false"

Interactive content

Forms remain open while their controls are used. Set the menu’s public minimum-width property when the content needs more room.

data-ui-auto-close="outside" --ui-dropdown-min-width
