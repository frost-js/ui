Tooltips

Default triggers

Tooltips appear on hover or focus, keeping the same supporting text available to pointer and keyboard users.

data-ui-toggle="tooltip" data-ui-title

HTML content

Enable HTML only when simple emphasis improves the message; content is sanitized by default.

data-ui-html="true"

Placement

Request a side explicitly when the surrounding layout provides enough space.

data-ui-placement="*"

Alignment

Position selects start, center, or end alignment along the chosen side.

data-ui-position="start|center|end"

Disabled controls

Place the tooltip on a focusable wrapper because disabled controls do not receive pointer or keyboard events.

tabindex="0"
