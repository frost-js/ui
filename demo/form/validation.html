Validation

Valid filled controls

Apply the validation state to a parent containing the control and its feedback.

.form-success .input-filled .valid-feedback
This address is available.
Name looks good.
TEAM-

Invalid filled controls

Error feedback should identify the problem and explain how to resolve it.

.form-error .input-filled .invalid-feedback
Enter a complete email address.
Choose a team.

Valid outline controls

Validation state updates the outline, label, and feedback together.

.form-success .input-outline .valid-feedback
This address is available.
Name looks good.
TEAM-

Invalid outline controls

Use the same parent state and feedback structure with outlined inputs.

.form-error .input-outline .invalid-feedback
Enter a complete email address.
Choose a team.
