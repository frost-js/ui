Containers

Responsive container

The default container stays fluid at smaller widths, then adopts a maximum width at each breakpoint.

.container
Responsive content boundary
Resize the viewport to see the outer gutters and maximum width change.

Breakpoint container

A breakpoint container remains full width until its named breakpoint, then follows the responsive maximum-width scale.

.container-md .container-sm|lg|xl|xxl
Medium breakpoint boundary
Full width below medium; constrained from medium upward.

Fluid container

A fluid container always uses the available width while retaining the framework’s horizontal container padding.

.container-fluid
Fluid content boundary
The content continues to expand with its allocated width.
