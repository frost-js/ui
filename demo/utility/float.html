Float

Logical directions

Start and end follow the document’s writing direction. Float-none returns an element to normal flow.

.float-start .float-end .float-none
Float start
Float end
Float none

Responsive floats

Add a breakpoint infix to enable start, end, or no float from that viewport width upward. Resize the page to see each item enter the float context.

.float-{sm|md|lg|xl}-{start|end|none}
.float-sm-start
.float-md-end
.float-lg-start
.float-xl-end
